# project_bpsmr

Repositori kolaborasi untuk proyek **project_bpsmr**.

## Status

Repositori masih kosong. Kode sumber dan struktur proyek akan ditambahkan kemudian.

## Kolaborasi

1. Clone repositori:
   ```bash
   git clone https://github.com/drwijaya/project_bpsmr.git
   ```
2. Buat branch untuk pekerjaan Anda:
   ```bash
   git checkout -b fitur/nama-fitur
   ```
3. Commit dan push, lalu buka Pull Request ke `main`.

## Aturan

- Jangan commit file rahasia (`.env`, kredensial, kunci).
- Satu branch untuk satu fitur/perbaikan.
- Sertakan deskripsi jelas pada setiap Pull Request.
